## 🌟 Executive Overview

**ExpenseTracker PRO** is an enterprise-grade financial command center designed around one immutable engineering principle: **personal and corporate financial intelligence, recording, and reconciliation should be instantaneous, zero-latency, private, and architecturally resilient.**

Modern wealth management and expense auditing are frequently broken across fragmented SaaS tools: clunky spreadsheets, privacy-invasive third-party aggregators that monetize consumer banking data, slow electron-based wrappers, and disconnected mobile apps. 

Operating on **Java 27** using Generational ZGC, **Spring Boot 4.1.1**, **Python 3.14**, and **Expo React Native**, ExpenseTracker PRO harmonizes four cooperating surfaces:
1. **🌐 Web Command Studio** — High-velocity browser desktop center with 12 luxury atmospheric themes, diffused ambient lighting, and sub-millisecond filtering.
2. **📱 Mobile Native Companion** — Expo React Native client supporting offline caching, native haptic feedback, SMS bank debit parsing, and biometric authentication.
3. **⚙️ Enterprise Core API** — Spring Boot microservices managing JWT/OAuth2/WebAuthn identity, business rule validation, audit trails, and Apache POI Excel analytics.
4. **🧠 AI Machine Learning Microservice** — Dedicated Python 3.14 FastAPI engine powering dual-model categorization, merchant index vectorization, transaction anomaly scoring, and automated retraining pipelines.

## 💎 Feature Portfolio

### 1. Unified Cash Flow Ledger & Dual-Stream Audit Trail

## ⚡ Performance Engineering & Java 27 Optimization

Operating on **Java 27 (Eclipse Temurin)** with **Spring Boot 4.1.1**, the platform leverages cutting-edge JVM capabilities:

- **Generational ZGC (`-XX:+UseZGC -XX:+ZGenerational`)**:
  - Millisecond-level pause times even under peak concurrent allocations.
  - Separates young and old generation collections, slashing garbage collection overhead by over 70% compared to standard G1GC.
- **Spring Virtual Threads (`spring.threads.virtual.enabled=true`)**:
  - Millions of concurrent virtual request threads managed by Project Loom.
  - Eliminates traditional thread pool starvation during blocking JDBC or network I/O calls.
- **Cold Boot Container Acceleration**:
  - Optimized multi-stage Docker build utilizing **Astral UV** package caching for Python.
  - Layered Spring Boot JAR execution (`org.springframework.boot.loader.launch.JarLauncher`) ensuring instantaneous application startup.

## 🚀 Quick Start Guide

<details open>
<summary><b>1. Launch Backend API (Spring Boot 4.1.1 on Java 27)</b></summary>
<br/>

```bash
git clone https://github.com/Yoge-2004/expense-tracker.git
cd expense-tracker

# Start the Spring Boot backend on http://localhost:8080
./mvnw spring-boot:run
```
</details>

<details open>
<summary><b>2. Launch Web Client Studio (Zero-Build Browser Execution)</b></summary>
<br/>

```bash
cd frontend
python3 -m http.server 5500
# Open http://localhost:5500 in your browser
```
</details>

<details open>
<summary><b>3. Launch Mobile Companion App (Expo React Native)</b></summary>
<br/>

```bash
cd mobile
npm install

# Start the Expo interactive development server
npx expo start
```
*Press `a` for Android Emulator, `i` for iOS Simulator, or scan the QR code with Expo Go.*
</details>

<details open>
<summary><b>4. Run via Multi-Stage Docker Container (Gateway Port 7860)</b></summary>
<br/>

```bash
# Package production Spring Boot artifact
./mvnw clean package -DskipTests

# Build unified multi-process container
docker build -t expense-tracker-prod .

# Run container exposing gateway port 7860
docker run --rm -p 7860:7860   -e SPRING_DATASOURCE_URL="jdbc:h2:mem:expensetrackerdb"   -e JWT_SECRET="your-256-bit-hex-secret-key-here"   expense-tracker-prod
```
</details>
